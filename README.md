# 小纳西妲 · Codex 桌面宠物

一只以《原神》纳西妲为灵感的非官方同人桌面宠物。图像为本项目生成的动画素材，并非游戏原始素材。

## 内容

- `pet.json`：Codex 自定义宠物配置，`spriteVersionNumber: 2`
- `spritesheet.webp`：1536 × 2288 透明动画图集，8 列 × 11 行
- `preview.png`：动作总览预览

图集包含九组标准状态动作：安静待机、向右移动、向左移动、招手、跳跃、受挫、等待、专注处理、审阅；另有 16 个视线方向。待机时轻轻闭眼，互动时招手、微笑。

## 安装

将整个目录复制到 `~/.codex/pets/nahida-companion/`，确保 `pet.json` 与 `spritesheet.webp` 位于同一目录。宠物动作何时播放由 Codex 的状态机制决定，图集本身不检测用户是否暂停工作。

这是 AI 辅助制作的非官方同人作品，与游戏发行方无关联。仓库未附开放授权许可。
